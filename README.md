# Документация системы менеджмента информационной безопасности

## Назначение репозитория

Репозиторий предназначен для централизованного ведения, хранения и контроля изменений документированной информации системы менеджмента информационной безопасности (СМИБ).

В репозитории хранятся политики информационной безопасности, частные политики, процедуры, инструкции, шаблоны и записи, используемые в рамках функционирования СМИБ.

## Структура репозитория

- `01-politika` - политика информационной безопасности верхнего уровня.
- `02-chastnye-politiki` - частные политики информационной безопасности.
- `03-procedury` - процедуры и регламенты.
- `04-instrukcii` - инструкции, шаблоны и чек-листы.
- `05-zapisi` - шаблоны записей и документирование результатов деятельности СМИБ.

## Порядок внесения изменений

Изменения в документированную информацию выполняются через отдельную рабочую ветку. Каждое изменение должно иметь информативное описание причины и содержания.

После завершения изменения выполняется проверка и создается запрос на слияние. Изменения основной ветки должны выполняться только после рассмотрения и утверждения.

Утвержденные редакции документов маркируются тегами Git для возможности однозначной идентификации версии и восстановления предыдущего состояния.

## Контроль версий

Git используется для:

- фиксации изменений;
- идентификации редакций;
- сохранения истории документов;
- сравнения различных редакций;
- восстановления предыдущих версий;
- контроля авторства и времени внесения изменений.

## Ответственность

Ответственные лица за разработку, проверку и утверждение документов назначаются в соответствии с установленными ролями и полномочиями в системе менеджмента информационной безопасности.
